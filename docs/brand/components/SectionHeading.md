# SectionHeading

SectionHeading opens a section with a mono eyebrow and a Newsreader headline carrying at most one italic word.

**Markup:** a `.sx-label` eyebrow, then `<h2 class="sx-h">…<em>word</em>…</h2>`. Size the headline with a type style: `display-l` for Night bands, `heading-1` for Day sections, `heading-2` in the app.

**The italic word** goes on the word that carries the promise (word, settled, across borders). On Night grounds it turns `brand-signal`; on Day it stays `ink`.

**Don't:** italicize more than one phrase; bold Newsreader; write an eyebrow that repeats the headline; number sections unless the content is a real sequence.
