# Logos

The Rising column, as single-ink SVGs at 64×64. Each file is one ink; `<img>` can't recolor it, so pick the file by ground.

**Line mark** (lockup, nav, footer, card, large brand moments):
- `sancus-column-deep.svg`: ink `brand-deep` (#123A35). Use on `surface-000`, `surface-100` and `brand-limestone`.
- `sancus-column-patina.svg`: ink `brand-signal` (#8CC7B5). Use on `brand-night` and the Night theme only.
- `sancus-column-verdigris.svg`: ink `brand-verdigris` (#1F7A6D). Small Day UI marks on white.

**Carved mark** (app icon, favicon, avatars; the column sits off-center at x +7, y +3, size 0.94):
- `sancus-column-carved-deep.svg`: disc in `brand-deep`. Use on light grounds.
- `sancus-column-carved-patina.svg`: disc in `brand-signal`. Use on Night.
- `sancus-column-carved-verdigris.svg`: disc in `brand-verdigris`. The default app icon and favicon on white.

The SANCUS wordmark is live text in Newsreader capitals (`wordmark` style), not a file. See [components/Logo.md](../components/Logo.md) for the lockup and inline-symbol markup.
